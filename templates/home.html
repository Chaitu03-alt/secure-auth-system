Security Architecture

Each layer independently hardened against credential attacks, session replay, and token exhaustion.

Two-Factor Authentication (TOTP)
RFC 6238 time-based one-time passwords. Compatible with Google Authenticator, Authy, and 1Password via standard 30-second time-step windows.
Tiered Rate Limiting
Per-endpoint and per-IP rate throttling configured to defeat brute-force and credential-stuffing attacks at the application layer.
Timing-Safe Password Hashing
Bcrypt with adaptive cost factor 12. Dummy password lookups on non-existent accounts prevent username enumeration via timing analysis.
CSRF Token Enforcement
Cryptographic tokens bound to ephemeral session nonces. All state-mutating requests require a valid per-session CSRF token.
Audit Event Log
Chronological event log capturing client IP address, timestamp, and multi-stage authentication state for each session lifecycle.
Containerized Deployment
Docker Compose topology with dedicated network boundaries between application and database layers. Production-ready isolation.
