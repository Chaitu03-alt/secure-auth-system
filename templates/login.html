Security Details

  • TOTP Two-Factor Authentication
    RFC 6238 time-based codes via Google Authenticator or Authy. Required after password verification.
  • Rate-Limited Endpoints
    Failed authentication attempts are tracked per IP. Repeated failures trigger a temporary lockout.
  • Bcrypt Password Verification
    Passwords verified with constant-time bcrypt comparison. Dummy lookups prevent timing-based enumeration.

Auth engine: HMAC-SHA1 TOTP
